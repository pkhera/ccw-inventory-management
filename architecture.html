Step-by-Step: User selects "London" warehouse

1
User interaction — FilterBar.vue
selectedLocation ref updates to "London" via v-model. This ref is a singleton exported from useFilters.js and shared across every view.
2
Watch fires — e.g. Dashboard.vue
Every view has a watcher on all four filter refs:
watch([selectedPeriod, selectedLocation, selectedCategory, selectedStatus], () => loadData())
3
Build filter params — useFilters.js getCurrentFilters()
Converts refs to a plain object for the API call:
{ warehouse: "London", category: "all", status: "all", month: undefined }
4
Parallel API calls — api.js via axios
Views issue multiple requests concurrently with Promise.all():
GET /api/dashboard/summary?warehouse=London GET /api/orders?warehouse=London GET /api/inventory?warehouse=London GET /api/backlog
5
Backend filtering — main.py apply_filters()
FastAPI receives query params and filters in-memory Python lists. Month/quarter handled by filter_by_month(). Results validated through Pydantic models before serializing to JSON.
apply_filters(inventory_items, warehouse="London", category=None, status=None)
6
State update — refs in view component
Raw data stored in ref() variables: allOrders.value = data. Computed properties re-evaluate automatically (KPI cards, chart data, filtered tables). Template re-renders only changed DOM nodes.

Frontend Views & Routes

/ Dashboard.vue

KPI summary cards, Order Health donut chart (SVG), Inventory Value by Category bar chart, Backlog shortcuts, Top Products table. Calls 4 endpoints in parallel.

/inventory Inventory.vue

Searchable, sortable table of all stock items with status badges (Low/Adequate/In Stock). Click-to-open detail modal. Warehouse + category filters only (no date dimension).

/orders Orders.vue

Status stat cards, expandable order rows with line-item sub-tables. Supports all four filters including date period and order status.

/spending Spending.vue

Revenue/cost/profit KPI cards, Monthly Revenue vs Costs grouped bar chart, Stacked monthly cost flow chart, Category breakdown, Recent transactions table.

/demand Demand.vue

Demand forecast table with trend indicators (increasing / stable / decreasing). Calls /api/demand — no filter support.

/reports Reports.vue

Quarterly summary table and Monthly trends chart. Pulls from /api/reports/quarterly and /api/reports/monthly-trends.

Vue 3 Reactivity Pattern

ref() — Mutable State

Used for filter state, raw API data, loading/error flags. Mutated via .value in script.

const allOrders = ref([])
const loading   = ref(true)
const error     = ref(null)

// on API response:
allOrders.value = data

computed() — Derived Data

Derived from refs. Cached, re-runs only when dependencies change. Used for KPI cards, chart data, filtered tables.

const statusData = computed(() => {
  const counts = { delivered: 0, ... }
  allOrders.value.forEach(o => {
    counts[o.status.toLowerCase()]++
  })
  return counts
})

watch() — Side Effects

Triggers data reload when any filter ref changes. Each view sets up its own watcher on the shared composable refs.

watch(
  [selectedPeriod, selectedLocation,
   selectedCategory, selectedStatus],
  () => loadData(),
  { immediate: true }
)

Data Loading Pattern

Consistent async pattern across all views with parallel fetches where independent.

const loadData = async () => {
  loading.value = true
  try {
    const [summary, orders] = await
      Promise.all([
        api.getDashboardSummary(filters),
        api.getOrders(filters)
      ])
    allOrders.value = orders
  } catch (e) { error.value = e.message }
  finally  { loading.value = false }
}

Backend Filtering — main.py

apply_filters()

Filters a list of items by warehouse, category, and status. Skips a filter if its value is None or "all". Case-insensitive matching.

def apply_filters(items, warehouse, category, status):
    if warehouse and warehouse != "all":
        items = [i for i in items
                 if i["warehouse"] == warehouse]
    if category and category != "all":
        items = [i for i in items
                 if i["category"].lower() == category]
    return items

filter_by_month()

Parses order_date ISO strings and matches against a YYYY-MM month or a quarter shorthand like Q1-2025.

QUARTER_MAP = {
    "Q1-2025": ["2025-01","2025-02","2025-03"],
    "Q2-2025": ["2025-04","2025-05","2025-06"],
    ...
}

def filter_by_month(items, month):
    months = QUARTER_MAP.get(month, [month])
    return [i for i in items
            if i["order_date"][:7] in months]
